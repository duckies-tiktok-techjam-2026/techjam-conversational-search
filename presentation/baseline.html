by Team Duckiesss

Shortcomings of the provided baseline agent

1
Provided

A clarification question each turn

Shortcoming

It never asks one.

The customer only reveals a constraint when asked for that attribute, so nine of the ten turns return no new information.

2
Provided

Per-session state and a user profile

Shortcoming

It reads only the current turn.

Constraints never accumulate, the profile is unused, and an intent override or a “no preference” reply is not handled.

3
Provided

Full-text search over 50,000 products

Shortcoming

One query shape: all keywords joined by OR.

It cannot require two attributes together, so a single rare word outranks a product matching the whole description.

4
Provided

A ranked Top-10 recommendation list

Shortcoming

It returns the index's first ten rows unchanged.

With no reranking stage, nothing demotes the wrong colour, an over-budget price, or an item the customer already rejected.
